# 미너비니 KR 스크리너

마크 미너비니의 Trend Template과 VCP 기준으로 코스피·코스닥 전 종목을 매 거래일 자동 스크리닝하고, 결과를 정적 웹페이지로 발행합니다. 서버가 필요 없고 운영 비용이 0원입니다.

```
상장 전 종목
    ↓  유니버스 정제 (우선주·스팩·ETF·관리종목·저유동성 제거)
    ↓  1단계  Trend Template 8조건
    ↓  필터    수급 20일 + 재무
    ↓  2단계  VCP 수축 탐지
워치리스트 → 돌파 / 셋업
```

---

## 실행

**맥** — `run-mac.command` 우클릭 → 열기
**윈도우** — `run-windows.bat` 더블클릭

맥에서 권한 오류가 나면 터미널에서 한 번만 아래를 실행하세요. zip을 풀면 실행 권한이 사라져서 생기는 문제입니다.

```bash
cd <이 폴더 경로>
bash run-mac.command
```

메뉴 순서는 처음이면 `5 → 2 → 4`, 그다음부터는 `3 → 4` 입니다.

## GitHub Pages 배포

1. 저장소를 만들고 코드를 푸시합니다.
2. **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/docs`로 지정합니다.
3. **Settings → Actions → General** → Workflow permissions를 `Read and write permissions`로 바꿉니다. 결과 JSON을 커밋해야 합니다.
4. **Actions** 탭에서 `일일 스크리닝`을 열고 `Run workflow` → `backfill` 체크 후 수동 실행합니다. 첫 실행은 20~40분 걸립니다.
5. 이후 평일 19시(KST)에 자동으로 돕니다.

주소는 `https://<사용자명>.github.io/<저장소명>/` 입니다.

DART 연동을 쓰려면 **Settings → Secrets and variables → Actions**에 `DART_API_KEY`를 등록하고 `config.yaml`에서 `fundamentals.dart_enabled: true`로 바꾸세요. 키는 [opendart.fss.or.kr](https://opendart.fss.or.kr)에서 무료 발급됩니다.

### DB는 왜 커밋하지 않나

일봉 DB는 수백 MB입니다. 매일 커밋하면 저장소가 금방 터집니다. Actions 캐시에 두고, 캐시가 만료되면 워크플로가 알아서 백필합니다. 저장소에는 24KB짜리 결과 JSON만 들어갑니다.

## Trend Template 8조건

| # | 조건 |
|---|---|
| 1 | 종가 > 150일선 & 200일선 |
| 2 | 150일선 > 200일선 |
| 3 | 200일선 상승 추세 (기간 방향 + 상승일 비율 동시 확인) |
| 4 | 50일선 > 150일선 > 200일선 |
| 5 | 종가 > 50일선 |
| 6 | 52주 최저 대비 +30% 이상 |
| 7 | 52주 최고 대비 -25% 이내 |
| 8 | RS Rating 70 이상 |

RS Rating은 기성품이 없어 직접 계산합니다. IBD 방식 가중 수익률을 전 종목에 대해 구한 뒤 1~99 백분위로 변환합니다.

```
RS = 0.4×(3개월) + 0.2×(6개월) + 0.2×(9개월) + 0.2×(12개월)
```

`config.yaml`의 `rs.rank_by_market`을 켜면 코스피·코스닥을 나눠 랭킹합니다. 코스닥 테마주가 상위권을 독식하는 게 거슬릴 때 쓰세요.

## VCP 탐지 방식

퍼센트 반전 지그재그로 스윙 고점·저점을 뽑고, 고점→저점 구간을 수축으로 봅니다. 그다음 마지막 수축에서 끝나는 모든 꼬리 구간을 후보로 놓고 검증해서 베이스 시작점을 찾습니다.

단순히 최근 N개 수축을 자르면 베이스 이전 추세 구간의 잔 스윙이 섞여 단조감소 판정이 깨집니다. 실제 차트에서 늘 일어나는 일이라 탐색 방식이 필요합니다.

성립 조건은 다음과 같습니다.

- 수축이 계단식으로 축소 (T1 > T2 > T3)
- 첫 조정 40% 이내, 마지막 조정 15% 이내
- 마지막 수축 거래량 / 첫 수축 거래량 ≤ 0.80
- 최근 5일 거래량 / 50일 평균 ≤ 0.85
- 현재가가 피벗 -8% 이내

돌파는 종가가 피벗을 넘고 거래량이 50일 평균의 1.5배 이상일 때입니다.

### 한국 시장 보정

상하한가 ±30% 구조 때문에 일간 변동성이 미국보다 큽니다. 스윙 임계값(`swing_threshold`)과 첫 수축 허용 깊이(`max_first_depth`)를 미국 원안보다 넉넉하게 잡아뒀습니다.

**이 값들은 반드시 백테스트로 재조정하세요.** 기본값은 출발점이지 정답이 아닙니다. 셋업이 하루 30개씩 나오면 조이고, 2주간 0개면 푸세요.

## 화면 구성

3분할 트레이딩 터미널입니다. 한 화면에서 판단이 끝나도록 설계했습니다.

- **좌 · 워치리스트** — 셋업/관심 종목. `↑↓`로 이동, `Enter`로 상세, `/`로 검색. 키보드만으로 훑을 수 있습니다.
- **중 · 캔들 차트** — 실제 봉차트에 이동평균 3개(50·150·200), 거래량, 피벗선(앰버), 손절선(적)을 얹었습니다. 셋업이 아닌 종목은 52주 고점선을 저항 기준으로 표시합니다. 돌파 거래량은 앰버로 강조됩니다.
- **우 · 시장 내부 + 섹터** — 200일선 위 비율과 1단계 통과 수의 추이 그래프, 업종별 RS 히트맵. 자금이 어느 섹터로 도는지 한눈에 보입니다.

시장 내부 추이는 매일 실행할 때마다 한 줄씩 쌓입니다. 며칠 돌려야 그래프가 채워집니다.

## 백테스트

`config.yaml`의 모든 임계값은 추정치입니다. 검증하지 않고 실매매에 쓰는 건 위험합니다. 이미 적재된 데이터로 과거 신호를 재현하고 결과를 측정하세요.

```bash
python run_screen.py --backtest          # 현재 설정으로 검증
python run_screen.py --grid              # 파라미터 조합 비교
python run_screen.py --backtest --start 2025-01-01
```

메뉴에서는 6번(백테스트), 7번(파라미터 탐색)입니다.

### 결과 읽는 법

가장 먼저 볼 숫자는 **기대값(R 배수)** 입니다. 승률이 아닙니다.

```
기대값  +0.797R
```

거래 한 건당 최초 리스크(진입가 - 손절가)의 0.797배를 벌었다는 뜻입니다.

| 기대값 | 판정 |
|---|---|
| 0.25R 초과 | 실매매 검토 가능 |
| 0 ~ 0.25R | 양수지만 얇음. 수수료·슬리피지에 취약 |
| 0 이하 | 이 설정으로 매매하면 안 됨 |

**국면별 표**를 반드시 확인하세요. `respect_regime`을 껐다 켜서 "시장이 나쁠 때 쉬어라"가 한국 시장에서도 맞는지 직접 검증할 수 있습니다.

**청산 사유별 표**가 건강한 모습은 이렇습니다. 손실은 짧고 이익은 깁니다.

```
추적익절   6건  평균 +20.78%
시간손절   5건  평균  +0.52%
손절       2건  평균  -7.92%
```

거래가 10건 미만이면 통계적으로 의미가 없습니다. 기간을 늘리거나 조건을 완화하세요.

### 신뢰성 설계

백테스트가 거짓말하는 가장 흔한 경로가 미래 정보 누출입니다. 두 가지로 막았습니다.

- 모든 판정은 `t` 시점까지의 데이터만 사용합니다. 슬라이싱을 한 곳으로 몰아 실수 여지를 없앴습니다.
- 진입가는 돌파 당일 종가입니다. 장 마감에 확정되는 실제 체결 가능 가격입니다. `entry_on_next_open`을 켜면 다음날 시가로 바꿀 수 있습니다.

수수료, 증권거래세, 슬리피지가 모두 반영됩니다. 기본값은 편도 0.015% + 매도세 0.18% + 슬리피지 0.15%입니다.

## 튜닝 가이드

| 증상 | 조정 |
|---|---|
| 후보가 너무 많다 | `min_rs_rating` 80~90, `max_last_depth` 0.10 |
| 후보가 며칠째 0개 | `swing_threshold` 0.04, `max_dryup_ratio` 0.95 |
| 잡주가 올라온다 | `min_marcap_eok` 3000, `min_avg_value_eok` 30 |
| 코스닥이 상위권 독식 | `rs.rank_by_market: true` |
| 수급 나쁜 종목 제외 | `flows.hard_filter: true` |

## 알아둘 것

**시장 국면을 먼저 보세요.** 미너비니가 반복해서 강조하는 지점입니다. 아무리 좋은 셋업도 지수가 조정 국면이면 실패율이 급등합니다. 상단 배너가 `관망`이면 셋업이 나와도 손을 대지 않는 게 원안에 맞습니다.

**스크리너는 후보를 좁혀줄 뿐 판단을 대신하지 않습니다.** 미너비니 본인도 통과 종목의 대부분을 버립니다. 차트 확인, 섹터 확인, 실적 발표 일정 확인이 그다음에 붙어야 완성입니다.

**손절 라인이 진입보다 먼저입니다.** 상세 패널의 `손절 라인`은 마지막 수축의 저점입니다. 진입 대비 리스크가 10%를 넘으면 셋업이 덜 여문 것이니 넘기세요.

데이터는 KRX 공개 정보이고 지연·오류가 있을 수 있습니다. 투자 권유가 아니며 모든 판단과 책임은 사용자 본인에게 있습니다.
